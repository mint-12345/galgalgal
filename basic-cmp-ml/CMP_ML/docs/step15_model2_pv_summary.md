# Step 15. Model 2: PV 를 어떤 raw row 에서 요약하는지에 따른 차이

- P/V 종류는 늘리지 않았습니다. Step 14 확장판과 정의가 같은 6개 조합만 사용했습니다: P4xV5, P4xV6, P8xV5, P8xV6, P11xV5, P11xV6
- training 만 사용했고 test / validation 은 사용하지 않았습니다. raw 파일은 수정하지 않았습니다.
- 제외 기준은 앞 단계와 같습니다: 연속 완전 중복 1,819행, MRR > 1,000 인 wafer + Stage 4개. fold 는 Step 8 의 같은 5-fold 입니다.
- 코드: `scripts/step15_model2_pv_summary.py`
- 결과: `reports/step15_model2_pv_summary/`, PV_proxy 표: `data/processed/step15/`
- 이번 단계는 비교만 했습니다. 최종 P/V 나 요약 방식은 선택하지 않았습니다.

## 1. 비교한 요약 방식

| 방식 | PV_proxy 정의 |
|---|---|
| A | 모든 raw row 의 mean(P × V) (Step 14 방식) |
| B | P × V 가 0 이 아닌 row 만의 mean(P × V) |
| C | P 가 0 이 아니고 V 도 0 이 아닌 row 만의 mean(P × V) |

- **B 와 C 는 6개 조합 모두에서 완전히 같은 값이 나왔습니다.** 값과 빈 값 위치가 모두 일치합니다. pressure 와 V 가 모두 0 이상이라 P × V ≠ 0 과 (P ≠ 0 이고 V ≠ 0) 이 같은 조건이기 때문입니다.
- 여기서 고른 row 들은 **센서값이 0 이 아닌 구간**일 뿐이며, polishing 구간이라고 해석하지 않았습니다.
- 조건을 만족하는 row 가 없는 wafer + Stage 는 PV_proxy 를 0 으로 만들지 않고 빈 값으로 두었습니다. 이런 sample 은 예측을 만들 수 없어 지표 계산에서 빠집니다. 빠진 개수는 아래에 따로 적었습니다.
- 모델은 이전과 같습니다. fold 마다 학습용 4개 fold 의 "PV_proxy 가 있는" sample 로만 절편 없는 최소제곱 k 하나를 구해 평가 fold 에 그대로 적용했습니다. k 는 물리 단위의 Preston coefficient 가 아닌 effective k 입니다.
- 방식 A 의 지표와 k 가 Step 14 확장판 결과와 같은 것을 확인했습니다.

## 7. 확인 결과 정리

- **PV_proxy 가 0 인 sample**: 방식 A 는 조합에 따라 195개 또는 199개, 방식 B 와 C 는 0개입니다.
- **PV_proxy 를 계산할 수 없는 sample**: 방식 A 는 0개, 방식 B 와 C 는 195개 또는 199개이며 모두 Chamber 경로 1-2-3 입니다.
- **1-2-3 의 큰 오차가 줄어드는가**: 줄어듭니다. 다만 두 가지가 섞여 있습니다. 첫째, 예측이 0 이던 sample 이 지표에서 빠집니다. 둘째, 남은 sample 에서도 오차가 줄어듭니다. 같은 sample 로 비교하면 1-2-3 RMSE 는 95.49 ~ 99.39 에서 58.08 ~ 67.26 으로 줄어듭니다. 그래도 1-2-3 R² 는 -228 ~ -304 로 여전히 크게 음수입니다.
- **4-5-6 에서 상관이 달라지는가**: 조합에 따라 다릅니다. V5 조합은 뚜렷하게 커집니다. P4xV5 는 0.0383 → 0.2643, P8xV5 는 0.0172 → 0.1974 입니다. V6 조합은 거의 그대로이거나 (P4xV6 -0.0137 → 0.0316, P8xV6 -0.0247 → -0.0100) P11 조합은 음의 방향으로 커집니다 (-0.0580 → -0.1555, -0.0627 → -0.1588).
- **기존 전체 평균 방식보다 일관되게 좋아지는가**: 같은 sample 로 비교할 수 있는 4-5-6 에서는 6개 조합 모두 5개 fold 전부 B 가 A 보다 RMSE 가 낮습니다. 그러나 4-5-6 R² 는 B 에서도 -0.42 ~ -0.93 으로 여전히 음수입니다. 즉 오차는 줄었지만 평가 fold 평균으로 예측하는 것보다 나은 수준은 아닙니다.
- **전체 범위 R²**: 방식 B 기준 P4 조합 0.1949 ~ 0.1981, P8 조합 0.1098 ~ 0.1192, P11 조합 -0.0405 ~ -0.0058 입니다. 방식 A 는 모두 -2.83 ~ -2.92 입니다. 다만 B 의 값은 195~199개 sample 이 빠진 상태의 값입니다.
- **effective k**: B, C 의 k 는 A 보다 작고 (예: P4xV5 0.000387 → 0.000304), fold 사이 변동도 더 작습니다 (변동계수 A 0.0049 ~ 0.0056, B 와 C 0.0013 ~ 0.0042).
- **B 와 C 는 모든 조합에서 동일합니다.** 따라서 두 방식 중 하나를 고르는 문제는 없습니다.
