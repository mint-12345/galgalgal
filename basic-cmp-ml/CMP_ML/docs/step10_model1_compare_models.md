# Step 10. Model 1: 같은 feature 에서 모델 종류만 바꾼 비교

- 입력 표: `data/processed/step7_wafer_stage_table_v1.csv` (training, 1,977행, feature 32개 그대로)
- fold: `data/processed/step8_cv_folds_v1.csv` 그대로
- 코드: `scripts/step10_model1_compare_models.py`
- 결과: `reports/step10_model1_compare/`
- WAFER_ID 는 입력에 쓰지 않았습니다. test / validation 은 사용하지 않았습니다.
- 이번 단계는 모델 종류에 따른 차이만 확인합니다. 최종 모델은 정하지 않았습니다.

## 비교한 모델

세부 튜닝은 하지 않았고 라이브러리 기본값을 썼습니다. 무작위성이 있는 모델만 random_state=42 로 고정했습니다.

| 모델 | 구성 | 모델 입력 열 |
|---|---|---|
| MLR | Step 9 와 같은 1차 다중선형회귀 (one-hot + 표준화 + LinearRegression) | 33 |
| POLY2 | one-hot + 표준화 → 2차 다항식(제곱항, 교차항) → LinearRegression | 594 |
| RF | one-hot + 숫자 그대로 → RandomForestRegressor 기본값 | 33 |
| XGB | one-hot + 숫자 그대로 → XGBRegressor 기본값 | 33 |

- 모든 전처리는 Pipeline 안에서 학습용 4개 fold 로만 fit 했습니다.
- MLR 예측은 Step 9 에 저장된 예측과 같은 것을 확인했습니다.
- 트리 모델은 크기에 영향을 받지 않으므로 숫자 열을 표준화하지 않았습니다.

## 결과를 읽을 때 확인된 사실

- **POLY2 는 일부 예측이 크게 벗어났습니다.** 예측값 범위가 -4,881.8 ~ 495.0 이고, 실제 MRR 범위 53.4 ~ 162.6 을 벗어난 예측이 95개입니다. 그중 72개가 Chamber 1-2-3 행입니다. 절대오차 중앙값은 3.73 으로 MLR 3.45 와 비슷하지만, 99% 분위수 99.1, 최대 4,970.8 입니다. 입력 열 594개를 학습 행 약 1,580개로 규제 없이 맞춘 결과입니다.
- **Chamber 1-2-3 안의 R² 는 fold 마다 크게 흔들립니다.** fold 당 이 경로 행은 약 73개이고 실제 MRR 표준편차가 약 3.9 로 작아서, 작은 오차 차이에도 R² 가 크게 달라집니다.
- **fold 평균과 모아서 계산한 값은 다를 수 있습니다.** 예를 들어 MLR 의 Chamber 1-2-3 R² 는 fold 평균 -0.679, 5개 fold 예측을 모아 계산하면 -0.621 입니다.
- **RF 와 XGB 의 가장 큰 오차는 같은 행입니다.** CHAMBER_PATH 가 other 인 2665292924 A (실제 78.28) 를 RF 는 121.68, XGB 는 151.31 로 예측했습니다. 이 wafer 는 Step 3 에서 Chamber 4 기록만 있던 묶음입니다.

| 모델 | 절대오차 중앙값 | 95% 분위수 | 99% 분위수 | 최대 | 실제 범위 밖 예측 |
|---|---|---|---|---|---|
| MLR | 3.451 | 10.721 | 13.677 | 20.604 | 5 |
| POLY2 | 3.734 | 27.375 | 99.102 | 4,970.842 | 95 |
| RF | 2.073 | 7.291 | 10.515 | 43.397 | 0 |
| XGB | 2.124 | 6.901 | 10.691 | 73.032 | 0 |
