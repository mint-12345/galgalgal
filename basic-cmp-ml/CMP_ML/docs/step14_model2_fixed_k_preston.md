# Step 14. Model 2: 고정 k Preston 모델 (MRR = k × P × V)

- training 만 사용했습니다. test / validation 은 사용하지 않았고, raw 파일은 수정하지 않았습니다.
- 제외 기준은 앞 단계와 같습니다: 연속 완전 중복 1,819행, MRR > 1,000 인 wafer + Stage 4개.
- 여러 CSV 에 걸친 wafer + Stage 25개는 모든 행을 합쳐 계산했습니다.
- fold 는 Step 8 의 같은 5-fold 입니다.
- 코드: `scripts/step14_model2_fixed_k_preston.py`
- PV_proxy 표: `data/processed/step14/step14_pv_proxy_table.csv`
- 결과: `reports/step14_model2_fixed_k/`
- 이번 단계는 비교만 했습니다. 최종 P 와 V 는 선택하지 않았습니다.

## 1. 모델 구성

**P 후보 (서로 더하거나 평균내지 않음)**

| 기호 | 변수 |
|---|---|
| P1 | PRESSURIZED_CHAMBER_PRESSURE |
| P2 | MAIN_OUTER_AIR_BAG_PRESSURE |
| P3 | CENTER_AIR_BAG_PRESSURE |
| P4 | RETAINER_RING_PRESSURE |
| P5 | RIPPLE_AIR_BAG_PRESSURE |
| P6 | EDGE_AIR_BAG_PRESSURE |

**V 후보 (rotation 값으로 만든 proxy)**

| 기호 | 정의 |
|---|---|
| V1 | abs(WAFER_ROTATION) |
| V2 | abs(STAGE_ROTATION) |
| V3 | abs(HEAD_ROTATION) |
| V4 | abs(WAFER_ROTATION - STAGE_ROTATION) |
| V5 | abs(WAFER_ROTATION - HEAD_ROTATION) |

- 데이터에는 wafer-pad 상대속도를 계산할 기하 정보가 없습니다. V1~V5 는 모두 속도 자체가 아니라 rotation 값으로 만든 proxy 입니다.
- 특히 V4 와 V5 는 실제 선속도가 아니라 두 rotation 값의 차이로 만든 상대회전 proxy 입니다.

**PV_proxy**
- 30개 P/V 조합마다 raw 의 각 행에서 PV(t) = P(t) × V(t) 를 먼저 계산했습니다.
- 그다음 wafer + Stage 안 모든 행의 PV(t) 평균을 그 sample 의 PV_proxy 로 썼습니다. mean(P) × mean(V) 가 아니라 mean(P × V) 입니다.
- 예: 371447024 A 의 P2×V1 은 mean(P × V) = 2404.054318 이고, mean(P) × mean(V) = 1985.094801 입니다.

**고정 k**
- fold 마다 학습용 4개 fold 의 sample 만으로 절편 없는 최소제곱 k 하나를 구했습니다: k = Σ(PV_proxy × MRR) / Σ(PV_proxy²)
- 평가 fold 에는 그 k 를 바꾸지 않고 적용해 예측 MRR = k × PV_proxy 를 계산했습니다.
- k 는 모든 sample 에 공통인 하나의 값입니다. sample 마다 다른 k 는 쓰지 않았습니다.
- **k 는 원래 물리 단위의 Preston coefficient 가 아닙니다.** PHM 데이터 값이 변환되어 있으므로, 이 연구 안에서만 쓰는 effective k 입니다. P 후보마다 값의 크기가 달라서, 서로 다른 조합의 k 크기끼리도 비교할 수 없습니다.

## 4. 결과를 읽을 때 확인된 사실

- **30개 조합 모두 R² 가 음수입니다.** 일반 경로 1,973행 기준 R² 평균은 -3.6393 ~ -2.8408, RMSE 평균은 58.9002 ~ 64.7428 입니다. R² 가 음수라는 것은 평가 fold 의 MRR 평균 하나로 예측하는 것보다 오차가 크다는 뜻입니다.
- **Chamber 경로 1-2-3 의 오차가 가장 큽니다.** 30개 조합의 1-2-3 RMSE 평균은 129.4559 ~ 136.4105 입니다.
  - 1위 조합 P4xV5 에서 1-2-3 sample 364개 중 199개는 PV_proxy 가 0 이라 예측이 0 입니다. 이 199개의 RMSE 는 151.63 이고, 1-2-3 전체 제곱오차의 74.95% 를 차지합니다.
  - PV_proxy 가 0 이 아닌 1-2-3 sample 165개도 예측 평균이 58.23 으로 실제 평균 150.84 보다 크게 낮고, RMSE 는 96.27 입니다.
- **Chamber 경로 4-5-6 은 예측 평균은 실제와 비슷하지만 sample 간 차이를 따라가지 못합니다.**
  - P4xV5 의 4-5-6 예측 평균은 77.74, 실제 평균은 76.56 입니다.
  - 4-5-6 안에서 PV_proxy 와 MRR 의 Pearson 상관은 P4xV5 에서 0.0383, 30개 조합 전체에서 -0.1773 ~ 0.2757 입니다.
  - 30개 조합의 4-5-6 RMSE 평균은 21.4918 ~ 30.4496, R² 평균은 -11.2744 ~ -5.0977 입니다.
- **PV_proxy 가 0 이 아닌 1-2-3 sample 안에서 PV_proxy 와 MRR 의 Pearson 상관은 30개 조합에서 0.1515 ~ 0.3702 입니다.**
- **두 경로가 요구하는 k 크기가 다릅니다 (참고용 계산, 모델 아님).** P4xV5 에서 PV_proxy 가 0 이 아닌 sample 만으로 경로별 절편 없는 k 를 계산하면 1-2-3 은 0.000829, 4-5-6 은 0.000358 입니다. 모든 sample 에 공통인 k 하나로는 두 경로를 함께 맞출 수 없는 구조입니다.
- **PV_proxy = 0 인 sample 수는 V 후보에 따라 다릅니다.**
  - V3, V5 조합: 196 ~ 200개, 모두 1-2-3
  - V1 조합: 237 ~ 240개 (1-2-3 223 ~ 225, 4-5-6 12 ~ 15)
  - V2 조합: 245 ~ 246개 (1-2-3 233 ~ 234, 4-5-6 12)
  - V4 조합: 219 ~ 220개 (1-2-3 212 ~ 213, 4-5-6 7)
- **상위 12개 조합은 모두 V5 또는 V3 을 사용합니다** (각 6개). 이 두 V 후보는 PV_proxy = 0 인 sample 이 가장 적습니다.
- **k 는 fold 사이에서 거의 변하지 않습니다.** 30개 조합의 k 변동계수는 0.0029 ~ 0.0096 입니다.
- 참고로 Model 1 의 Step 12 Baseline Random Forest 는 같은 5-fold 에서 일반 경로 RMSE 평균이 3.5145 였습니다.
