# Step 20. Hybrid 고정 상태에서 k(x) XGBoost 설정 제한 비교

- 대상: CHAMBER_PATH = 4-5-6 의 1,609개 sample, Step 8 의 같은 5-fold
- training 만 사용했습니다. test / validation 은 사용하지 않았고, raw 파일은 수정하지 않았습니다.
- 코드: `scripts/step20_hybrid_xgb_tuning.py`, 결과: `reports/step20_hybrid_xgb_tuning/`
- **최종 XGBoost 설정은 선택하지 않았습니다.**

## 1. 고정한 것

- 구조: MRR_pred = k_pred(x) × PV_proxy, k_target = 실제 MRR / PV_proxy
- PV proxy: Step 19 의 1위 조합 P9 × V3 (P9 = pressure 6개 전체의 raw row 별 평균, V3 = abs(HEAD_ROTATION))
- PV 계산: P 와 V 가 모두 0 이 아닌 raw row 만의 mean(P × V). Step 19 와 같은 값인 것을 확인했습니다.
- feature: Step 18 / 19 의 C_full 31개. 추가하거나 삭제하지 않았습니다.
- k 표준화: fold 마다 학습 sample 로만 평균과 표준편차를 구해 표준화하고, 예측 후 원래 k 단위로 되돌립니다. 평가 fold 통계는 쓰지 않았습니다.
- XGBoost 고정값: subsample = 0.9, colsample_bytree = 0.9, random_state = 42. reg_alpha, reg_lambda, gamma 등은 Step 18 기본값 그대로 두고 탐색하지 않았습니다.
- k_pred 에 clipping 이나 평가 fold 값을 이용한 보정을 하지 않았습니다.

## 2. 비교한 설정

n_estimators {300, 600, 900} × max_depth {2, 3, 4} × learning_rate {0.03, 0.05, 0.1} × min_child_weight {1, 3} = **54개 설정**

54개 설정의 최종 MRR RMSE 평균 분포는 최소 3.5693, 25% 3.6094, 중앙값 3.6360, 75% 3.7899, 최대 4.3663 입니다.

## 10. 확인한 내용

- PV_proxy 가 Step 19 의 P9 × V3 값과 완전히 같은 것을 확인했습니다.
