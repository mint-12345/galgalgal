# Step 4. wafer + Stage 안에서 공정 값의 시간 변화

- 대상: training 공정 파일과 training MRR 파일. test / validation 은 열지 않았습니다.
- raw 파일은 수정하지 않았습니다. 분석할 때만 같은 파일에서 바로 윗줄과 25개 컬럼이 모두 같은 1,819행을 뺐습니다. 분석 행은 670,925입니다.
- Step 3 의 특이한 wafer + Stage 는 빼지 않았습니다.
- feature 생성과 모델 학습은 하지 않았습니다.
- 확인 코드: `scripts/step4_inspect_within_wafer_timeseries.py`
- 시간 변화 그래프: `reports/figures/step4_timeseries_*.png`
- 묶음별 압력 구간 목록: `reports/step4_air_bag_on_blocks_per_group.csv`

## 2. 값들이 시간에 따라 움직이는 방식

**Pressure**
- MAIN_OUTER, CENTER, RIPPLE, EDGE 네 air-bag 압력은 함께 켜지고 함께 꺼집니다. 넷 다 0 이 아닌 행 404,411, 넷 다 0 인 행 263,970, 섞인 행은 2,544 입니다.
- 네 압력이 모두 0 이 아닐 때는 PRESSURIZED_CHAMBER 와 RETAINER_RING 압력도 거의 항상 0 이 아닙니다 (404,411행 중 404,408행).
- 압력이 켜진 구간 안의 모양이 반복됩니다. 약 115초 동안 일정한 높은 값이 이어지고, 약 20초 동안 낮은 값으로 바뀐 뒤, air-bag 은 0 이 되고 RETAINER_RING 만 약 7,000 으로 몇 초 튄 다음 모두 0 이 됩니다.

**Chamber**
- 압력 구간의 경계가 Chamber 경계와 맞지 않습니다. Chamber 4→5→6 예시의 두 번째 압력 구간은 Chamber 5 에서 시작해 Chamber 6 까지 끊기지 않고 이어집니다.
- Chamber 1→2→3 예시 343446924 A 는 기록이 압력 구간 중간부터 시작하고, 두 번째 압력 구간은 Chamber 1→2→3 에 걸쳐 이어집니다.

**Rotation**
- 압력 구간 안에서 WAFER_ROTATION 이 약 35 인 부분과 STAGE_ROTATION 이 약 131, 262 인 부분이 나타납니다.
- 순서는 구간마다 같지 않습니다. 대부분은 WAFER_ROTATION 약 70초 뒤 STAGE_ROTATION 이 켜지지만, -4226160396 B 의 첫 압력 구간은 STAGE_ROTATION 이 먼저 켜지고 WAFER_ROTATION 은 0 입니다.
- 두 rotation 은 압력이 0 인 시간에도 자주 켜집니다. 예를 들어 -4027511786 A 의 Chamber 5 는 압력이 0 인데 WAFER_ROTATION 이 약 35 이고, 압력 구간이 없는 343446936 A 에서도 STAGE_ROTATION 이 켜집니다.
- HEAD_ROTATION 은 전체 행의 93% 가 156.8 또는 160 이고, 압력 상태와 관계없이 짧게 약 190 으로 올라갑니다.

**Slurry flow**
- SLURRY_FLOW_LINE_A, B 는 압력이 켜진 행에서 100% 0 이 아니지만, Chamber 4 에서는 압력이 꺼진 행의 95% 에서도 0 이 아닙니다.
- SLURRY_FLOW_LINE_C 는 압력 구간 대부분에서 약 430~450 이고, 압력 구간의 마지막 낮은 압력 부분에서 0 으로 떨어집니다.

## 3. 전체 training 에서 본 압력 구간

| Chamber 패턴 | 묶음 | 100초 넘는 압력 구간 0번 | 1번 | 2번 | 3번 이상 |
|---|---|---|---|---|---|
| 4→5→6 | 1,609 | 1 | 524 | 1,080 | 4 |
| 1→2→3 | 368 | 280 | 75 | 13 | 0 |

- Chamber 4→5→6 묶음에서 첫 번째 긴 구간은 거의 모두 Chamber 4 에 있고 길이 중앙값은 138초입니다. 두 번째 긴 구간은 대부분 Chamber 5→6 에 걸쳐 있고 약 212초에 시작해 137초 이어집니다.
- Chamber 1→2→3 묶음 368개 중 203개는 네 air-bag 압력이 켜진 행이 전혀 없습니다.

## 4. 결론: 연마 구간을 데이터만으로 구별할 수 있는가

**구별할 수 있는 것.** "네 air-bag 압력이 모두 0 이 아닌 구간"과 "모두 0 인 구간"은 뚜렷하게 나뉩니다. 값이 정확히 0 인지 아닌지로 갈리므로 임계값을 정할 필요가 없고, 섞인 행은 0.4% 뿐입니다. 이 구간에서 chamber 압력, retainer ring 압력, slurry flow 도 함께 켜집니다.

**확실하지 않은 것.** 이 압력 구간이 실제 연마 구간인지는 데이터만으로 확인할 수 없습니다.
- 공식 설명자료는 air-bag 압력들을 "wafer placement 관련 압력"이라고만 설명합니다. 연마 여부를 알려주는 컬럼은 없습니다.
- Chamber 4→5→6 묶음 대부분에는 같은 모양의 압력 구간이 두 번 있습니다. MRR 은 묶음당 하나라서 어느 구간이 재료를 제거했는지 알 수 없습니다. MRR 중앙값은 압력 구간이 Chamber 4 에만 있는 묶음 76.60, Chamber 4~6 에 있는 묶음 76.55 로 거의 같습니다.
- Chamber 1→2→3 묶음 203개는 압력 구간이 전혀 없는데도 MRR 이 있습니다. MRR 중앙값은 압력 구간이 없는 묶음 151.70, 있는 묶음 150.21~151.91 로 비슷합니다.
- rotation 과 slurry flow 는 압력이 0 인 시간에도 켜지므로 이 값들만으로는 구간이 나뉘지 않습니다.

따라서 연마 구간의 기준은 정하지 않았습니다. 다음 단계에서 이 압력 구간을 어떻게 다룰지 정해야 합니다.

참고: Chamber 1→2→3 묶음에는 MRR 이 4,000 을 넘는 값이 있습니다. 이번 단계에서는 따로 확인하지 않았습니다.
