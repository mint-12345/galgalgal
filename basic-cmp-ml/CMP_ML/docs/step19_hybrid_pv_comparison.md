# Step 19. Hybrid 구조에서 P/V proxy 12개 조합 비교

- 대상: CHAMBER_PATH = 4-5-6 의 1,609개 sample, Step 8 의 같은 5-fold
- training 만 사용했습니다. test / validation 은 사용하지 않았고, raw 파일은 수정하지 않았습니다.
- 구조는 고정했습니다: MRR_pred = k_pred(x) × PV_proxy, k_target = 실제 MRR / PV_proxy
- k(x) 모델은 Step 18 과 같은 standardized-target XGBoost 입니다. fold 마다 학습 sample 로만 표준화하고 예측을 원래 k 단위로 되돌립니다. XGBoost 설정은 Step 10 기본값이고 튜닝하지 않았습니다.
- feature 는 Step 18 의 C_full 31개만 사용했습니다. WAFER_ID, 실제 MRR, k_target, CHAMBER_PATH 는 입력하지 않았습니다.
- 코드: `scripts/step19_hybrid_pv_comparison.py`, 결과: `reports/step19_hybrid_pv_comparison/`
- **최종 P/V 는 선택하지 않았습니다.**

## 1. 비교한 P/V 와 PV_proxy

| P 후보 | 정의 |
|---|---|
| P4 | RETAINER_RING_PRESSURE |
| P8 | air-bag 4개 + retainer ring, 5개의 행별 평균 |
| P9 | pressure 6개 전체의 행별 평균 |
| P11 | 정규화한 5개(air-bag 4개 + retainer ring)의 행별 평균 |

| V 후보 | 정의 |
|---|---|
| V3 | abs(HEAD_ROTATION) |
| V5 | abs(WAFER_ROTATION - HEAD_ROTATION) |
| V6 | abs(STAGE_ROTATION - HEAD_ROTATION) |

- V5 와 V6 은 실제 선속도가 아니라 rotation 차이로 만든 relative-motion proxy 입니다.
- PV_proxy 는 P 와 V 가 모두 0 이 아닌 raw row 만의 mean(P × V) 입니다 (Step 15 nonzero 방식과 동일).
- **12개 조합 모두 1,609개 sample 전부에서 PV_proxy 를 계산할 수 있습니다.** 계산 불가 0개, 값이 0 인 sample 0개입니다. 계산에 쓰인 row 수는 조합별로 최소 24개, 중앙값 296~302개, 최대 1,951~2,012개입니다.
- **P11 정규화 기준**: fold 마다 학습 sample 의 raw row 중 0 이 아닌 값의 중앙값을 씁니다. 이번 분석은 4-5-6 만 다루므로 학습 row 도 4-5-6 학습 sample 의 row 입니다.
