# Step 11. Model 1 feature 후보 비교

- 기준: Step 7 feature 표(Baseline), Step 8 의 같은 5-fold
- training 만 사용했습니다. test / validation 은 사용하지 않았고, raw 파일은 수정하지 않았습니다.
- 코드: `scripts/step11_build_candidate_tables.py` (후보 표), `scripts/step11_compare_feature_candidates.py` (비교)
- 후보 표: `data/processed/step11/`
- 결과: `reports/step11_feature_candidates/`
- 이번 단계는 비교만 했습니다. feature 구성이나 모델을 최종 선택하지 않았습니다.

## 1. feature 구성

| 구성 | 추가한 값 | feature 수 |
|---|---|---|
| Baseline | Step 7 표 그대로 | 32 |
| C1_chamber | 압력 6개, SLURRY A/B/C, WAFER/STAGE ROTATION 의 Chamber 1~6 별 평균 66열 + Chamber 1~6 별 행 비율 6열 | 104 |
| C2_airbag | 네 air-bag pressure 가 모두 0 이 아닌 행의 비율 1열 | 33 |
| C3_usage | usage 4개의 시간순 마지막 값 4열 + 마지막 값 - 처음 값 4열 | 40 |
| C4_combined | C1, C2, C3 추가 열 모두 | 113 |

- 후보 표는 Step 7 과 같은 제외 기준(연속 완전 중복 1,819행, MRR > 1,000 인 4개)으로 raw 에서 계산했습니다.
- 같은 데이터로 Baseline 숫자 30열을 다시 계산해 Step 7 표와 같은 것을 확인했습니다.
- 여러 CSV 에 걸친 wafer + Stage 25개는 모든 파일의 행을 합친 뒤 TIMESTAMP 순으로 정렬해 계산했습니다. 같은 TIMESTAMP 는 원래 파일 행 순서를 유지했습니다.
- C2 의 비율은 네 air-bag pressure 가 모두 0 이 아닌 행의 비율일 뿐이며, 연마 여부로 해석하지 않았습니다.

**C1 의 빈 값**
- 지나지 않은 Chamber 의 평균은 0 이 아니라 빈 값으로 두었습니다. 빈 칸은 65,296개입니다.
- Chamber 1~3 평균은 1,613행, Chamber 4 는 364행, Chamber 5 는 367행, Chamber 6 은 366행이 빈 값입니다.
- Chamber 별 행 비율은 해당 Chamber 기록이 없으면 실제로 0 이므로 0 으로 두었습니다.

**C3 에서 확인된 값**
- USAGE_OF_POLISHING_TABLE 의 마지막 값 - 처음 값이 음수인 wafer + Stage 가 1개 있습니다 (-31.85). 나머지 usage 는 음수가 없습니다.

## 5. 결과를 읽을 때 확인된 사실

- **C2_airbag, C3_usage 는 Baseline 과 차이가 작습니다.** 세 모델 모두 전체 R² 평균 변화는 0.001 이내, 전체 MAE 와 RMSE 평균 변화는 0.06 이내입니다.
- **MLR 에 C1, C4 를 넣으면 MAE 는 줄지만 RMSE 는 커지고 fold 마다 크게 흔들립니다.**
  - 전체 MAE 는 Baseline 4.20 에서 C1 3.85, C4 3.78 로 줄었습니다. 절대오차 중앙값도 3.45 에서 3.10, 3.02 로 줄었습니다.
  - 전체 RMSE 는 fold 3 에서 Baseline 5.65 가 C1 8.39, C4 7.56 으로 커졌습니다.
  - 가장 큰 오차는 fold 3 의 -4035511574 B (4-5-6, 실제 88.04) 입니다. C1 은 214.64, C4 는 202.58 로 예측했고, Baseline MLR 의 오차는 10.26 이었습니다.
  - 절대오차 최대값은 Baseline 20.60, C1 126.60, C4 114.54 입니다.
- **XGB 에 C1, C4 를 넣었을 때 전체 RMSE 가 줄어든 차이는 대부분 other 행 하나에서 나옵니다.**
  - 2665292924 A 의 절대오차가 Baseline 73.03 에서 C1 1.99, C4 3.74 로 줄었습니다. 이 행은 fold 4 에 있고, fold 4 전체 RMSE 는 4.95 에서 3.62, 3.49 로 줄었습니다.
  - other 4행을 빼고 5개 fold 예측을 모아 계산한 RMSE 는 Baseline 3.452, C1 3.498, C4 3.449 입니다.
  - Chamber 경로 1-2-3 안의 RMSE 평균은 Baseline 2.75 에서 C1 2.80, C4 2.87 로 커졌습니다.
- **RF 는 모든 후보에서 전체 RMSE 평균 변화가 0.06 이내입니다.** other 행에서는 2665292924 A 오차가 43.40 에서 C1 20.97, C4 21.54 로 줄고, 3015014228 B 오차가 18.81 에서 32.95, 33.87 로 커졌습니다.
- **Chamber 경로 1-2-3 안의 R² 는 이전 단계처럼 fold 마다 크게 흔들립니다.** fold 당 이 경로 행이 약 73개이고 실제 MRR 표준편차가 약 3.9 로 작기 때문입니다.
