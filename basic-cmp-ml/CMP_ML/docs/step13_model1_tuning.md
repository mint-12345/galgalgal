## 1. 비교한 설정

**Random Forest (54개)**
- n_estimators {300, 600} x max_depth {None, 10, 20} x min_samples_leaf {1, 2, 4} x max_features {sqrt, 0.7, 1.0}
- 나머지는 Step 10 과 같습니다: one-hot + 숫자 그대로 → RandomForestRegressor(random_state=42, n_jobs=1)
- 설정 x fold 학습 작업을 여러 프로세스에서 동시에 실행했지만, 각 학습은 단일 스레드와 고정 seed 입니다.

**XGBoost (18개)**

**기준**

**XGBoost 에서 확인된 사실**
- **조정한 18개 설정 모두 Chamber 경로 1-2-3 RMSE 가 기본 설정보다 큽니다.** 18개 모두 5개 fold 전부에서 크고, 평균 차이는 +0.3319~+1.0381 입니다. 조정한 18개 설정은 모두 subsample=0.9, colsample_bytree=0.9 가 고정된 상태이고, 기본 설정은 두 값이 1.0 입니다.
- **상위 설정의 일반 경로 RMSE 개선은 주로 4-5-6 에서 나옵니다.** 1위 설정은 4-5-6 RMSE 가 평균 0.1307 낮고(4/5 fold), 1-2-3 RMSE 는 평균 0.3710 높습니다(0/5 fold). 일반 경로 전체로는 평균 0.0524 낮고 3/5 fold 에서 낮습니다.
- **1-2-3 안의 R² 는 기본 0.4758 에서 상위 설정 0.2544~0.3482 로 낮아졌습니다.**
- **max_depth 가 클수록, learning_rate 가 클수록, n_estimators 가 많을수록 일반 경로 RMSE 평균이 낮았습니다.** 조정한 설정 기준 max_depth 2/3/4 평균은 3.9138/3.5794/3.4587 입니다. 가장 큰 값은 격자의 끝(max_depth=4, learning_rate=0.1, n_estimators=600)입니다.
- 1위와 2위(XGB_n300_d4_lr0.1)의 같은 fold 차이는 평균 +0.0147 이고, 2위가 5개 fold 모두에서 1위보다 RMSE 가 큽니다.

## 4. 결과를 읽을 때 주의할 점

- **같은 5-fold 로 여러 설정을 비교해 상위 설정을 고르면, 그 설정의 5-fold 점수는 실제보다 조금 좋게 보일 수 있습니다.** 이번 차이(RF 약 0.03, XGB 일반 경로 약 0.05)는 1위 설정과 기본 설정의 일반 경로 RMSE fold 간 표준편차(0.1496~0.2001)보다 작습니다.
- 일반 경로 평균만 보면 XGB 상위 설정이 좋아 보이지만, 1-2-3 경로에서는 모든 조정 설정이 기본보다 나빴습니다. RF 상위 설정은 두 경로 모두 기본과 비슷하거나 조금 낫지만, min_samples_leaf=2 설정은 other 행 오차가 커졌습니다.
