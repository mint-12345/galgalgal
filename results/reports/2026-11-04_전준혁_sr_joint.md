# 공동 SR 후속 실험 결과 — A-456·B-456 공통 형태 f(x) + 테이블별 계수

> **사후 후속 실험(계획 커밋 이후 실행), 정식 SR 판정은 바꾸지 않음.**
> 정식 SR(PR #27)과 교차 적용(main `61d7178`) 결과를 본 뒤 세운 계획(`docs/plans/2026-11-04_joint_sr_plan.md`, 커밋 `3949cb4`)대로 실행했다.
> 모든 성능 수치는 train+val의 `folds_v1.csv` 25 fold 오차이고, 식 탐색·선택에 같은 데이터를 썼으므로 **낙관적**이다. 독립 검증이 아니다.
> 작성: 전준혁 · 실행 2026-11-05 · 매뉴얼: 김혜연 `공동SR_실험매뉴얼_1104` · 브랜치 `sr/joint`(로컬)

## 요약

**판정(계획 9절): 공통 형태 없음.** 두 테이블 모두에서 공동 모형이 같은 변수의 테이블별 선형회귀 (가)보다 유의하게 낮지 않다
(A-456 RMSE 차이 −0.026, p = 0.56 / B-456 −0.571, p = 0.26). 공동 모형은 테이블별 정식 SR보다 A 0.25, B 0.13 높다.

- 공통 f를 찾지 못한 것은 아니다. f 하나에 테이블별 a·b만 주어도 두 테이블 MRR을 평균 예측보다 훨씬 잘 맞춘다(A 6.30 → 4.49, B 9.03 → 4.31).
  하지만 **그 f의 비선형 형태는 같은 변수를 선형으로 쓴 것보다 나은 정보를 주지 못했다.**
- B-456의 큰 차이(−0.571)는 웨이퍼 1장(연마 시간 98초) 때문이다. 그 웨이퍼에서 선형회귀가 외삽으로 크게 틀린 것이고,
  이 웨이퍼를 빼면 차이는 −0.042(p = 0.42)다(사후 민감도, 판정 미사용).
- 결론은 **예측 구조에 대한 것**이다. 물리적 인과나 "공통 관계가 없음"을 입증하지 않는다. 유의하지 않음은 없음과 다르다.

## 1. 무엇을 했나

| 항목 | 내용 |
|---|---|
| 모형 | MRR_g = a_g · f(x) + b_g. f의 형태·변수·내부 상수는 두 테이블 공통, a_g·b_g만 테이블별. 테이블 구분값 g는 f에 들어가지 않음 |
| 데이터 | `features_v1.csv` + `wafer_table.csv` MRR(train+val, 이상치 제외). 공통 후보 14개 값이 모두 있는 웨이퍼 **A-456 940 / B-456 951 = 정식 SR 웨이퍼와 같음** |
| 후보 변수 | 정식 SR 후보(테이블별 10개)의 합집합 14개: auc_PCHAMBER_s1, auc_MAIN_OUTER_s1, auc_SLURRY_C_s1, P1_on, std_POLISH_TABLE_s1, dur_POLISH_s1, std_MEMBRANE_s1, mean_DRESSER_TABLE_s2, mean_WAFER_ROT_s1, since_MEMBRANE_w, std_PSHEET_s1, auc_RETAINER_s1, frac_hi, since_BACKING_FILM_w |
| 척도 | 변수 ÷ \|중앙값\|. 주 처리 = 두 테이블 합산, 민감도 = 테이블별, fold 학습 쪽 합산 |
| fold | `folds_v1.csv` 25개. 학습 = 두 테이블 학습 조각 합집합, 평가는 테이블별. A·B 공유 WAFER_ID 405개는 반복 5회 모두 같은 조각(어긋남 0) |
| 1단계 | 정식 SR 파레토 281행(고유 246, 변수 없는 식 5개 제외 → 241개)을 f로 두고 fold마다 f 상수 + a_g·b_g 재적합 |
| 2단계 | PySR 2.7.2 `TemplateExpressionSpec`(`a[g] * f(14개) + b[g]`, 매개변수 a·b 길이 2)로 새 탐색. 정식 SR 설정 그대로(시드 42~51, 500회, populations 31, population_size 27, f 복잡도 ≤ 20, 같은 연산자·가중치·중첩 금지·지수 차단 loss). 후보 f를 fold 재적합으로 평가해 1-표준오차 규칙으로 선택 |
| 판정 | 계획 9절(매뉴얼 8절): 테이블별 보정 t-검정(공동 − (가), MSE) + 정식 SR과의 RMSE 차이 ≤ SE |

인공 데이터 검증(라벨 없음): 템플릿이 실행되고, f는 x만 받으며, a·b가 테이블별로 복원되고(참값 3·−2 / 10·40 → 3.000·−1.997 / 9.998·39.998),
지수 차단 loss가 템플릿에서도 변수 지수를 막았다(차단 0개, 차단 없을 때 10개 중 9개). 그래서 대안(목표값 표준화 근사)은 쓰지 않았다.

## 5. 질문별 답

1. **A·B 공통 SR 수식이 발견되었는가?**
   공통 f는 찾았고, 테이블별 a·b만으로 두 테이블을 평균보다 훨씬 잘 맞춘다. 하지만 미리 정한 기준으로는 **"공통 형태 없음"**이다.
   그 f는 같은 변수의 선형회귀보다 유의하게 낫지 않았다.
2. **최종 공통 수식:** f = (log(P1_on) − auc_RETAINER_s1) · log(auc_SLURRY_C_s1 · (auc_PCHAMBER_s1 + 0.090) · auc_MAIN_OUTER_s1).
   변수는 합산 \|중앙값\|으로 나눈 값이다.
3. **그룹별 계수:**
   - 원척도 f: A-456 a = 34.51, b = 76.55 / B-456 a = 42.31, b = 87.04.
   - f를 표준화하면 a = 5.68 / 6.97, b = 72.24 / 81.76. 부호가 같고 a의 비는 0.82다.
4. **기존 개별 SR 대비:** A-456 +0.247(+5.8%), B-456 +0.134(+3.2%). 두 테이블 모두 유의하게 나쁘다(p = 0.0003, 0.040).
   개별 SR 값은 식 선택에 같은 fold를 써서 낙관적이므로 실제 차이는 이보다 작을 수 있다.
   바깥 fold 하나를 탐색에서 뺀 검증에서는 공동 SR이 개별 SR보다 A 0.23, B 0.07 높았다(fold 하나, 검정 없음).
5. **선형회귀보다 비선형 설명력이 있는가:** 없다고 본다.
   - 같은 변수 선형회귀 대비 A −0.026이고, B −0.571도 극단 웨이퍼 하나를 빼면 −0.042다.
   - 공통 기울기 선형회귀 (나)보다는 A에서 유의하게 낫다(−0.189, p = 0.004).
   - 따라서 공동 모형의 이점은 비선형 형태가 아니라 **테이블별 기울기**에서 온 것으로 보인다.
   - 바깥 fold 제외 검증에서는 **개별 SR도 같은 후보의 선형회귀와 같았다.** 비선형 이점이 없는 것은 공동 SR만의 문제가 아니다.
6. **통계검정:** 3절 표. 판정에 쓰는 (가) 대비 검정은 두 테이블 모두 유의하지 않고, (다) 대비로는 두 테이블 모두 유의하게 나쁘다.
7. **소모품 교체·시간 변화에 계수가 안정적인가:**
   - B-456은 안정적이다(a 변동계수 0.03).
   - A-456은 a가 교체 구간마다 12~41로 흔들린다(0.42). 정식 SR에서도 A 상수의 변동계수가 컸다(0.59).
   - 절편 b는 두 테이블 모두 안정적이다.
   - 계수를 고정된 물리 상수로 해석하지 않는다.
8. **공통 물리 관계는 어느 수준까지 주장할 수 있는가:**
   - 말할 수 있는 것: "두 테이블의 MRR은 압력·슬러리 적분 같은 같은 변수 묶음에 대해 테이블별 수준과 기울기가 다른 비슷한 단조 관계를 보인다."
   - 말할 수 없는 것: 공통 비선형 형태나 공통 물리 법칙. 압력·유량 적분은 설정과 연마 시간이 섞인 양이고, 인과도 보이지 않았다.
   - 정식 SR 판정("일관된 경험식을 찾지 못함")과 같은 방향이다.
   - 관찰로만 적을 것: 공동 탐색 두 번과 B-456 개별 탐색에서 "리테이너 압력 관련 항 × log(압력·슬러리 적분의 곱)" 골격이 반복해서 나왔다.
     다만 선형회귀보다 낫지 않으므로 이 골격을 법칙이라고 부를 근거는 아니다.
9. **포스터에 넣을 수 있는가:** 넣을 수 있다. 단 "사후 후속 탐색"으로 표기하고 판정 한 줄과 그림 1개만 넣는다.
   - 그림 설명에 "B의 선형회귀 4.88은 극단 웨이퍼 1장 때문, 빼면 4.33"을 함께 적는다.
   - 제안 문구: *공통 f + 테이블별 계수의 공동 SR은 같은 변수의 선형회귀와 차이가 없었고(p = 0.56, 0.26), 개별 SR보다 RMSE가 0.13~0.25 높았다 → 공통 비선형 형태의 근거는 찾지 못함(사후 탐색).*

## 7. 한계와 추가 검증

- **선택 편향:** 1·2단계 모두 탐색·선택과 평가에 같은 데이터를 썼다. 부분 중첩과 바깥 fold 하나 제외 검증은 일부만 분리한다.

- **test 평가:** 사전확정 4.1의 test 1회는 팀 결정 사항이라 하지 않았다.
- **B-456 극단 웨이퍼:** 선형 기준선이 웨이퍼 1장에 크게 흔들려 B의 (가) 검정은 검정력이 낮다. 이런 웨이퍼를 어떻게 다룰지 팀이 정해야 한다(CLAUDE.md 13절의 긴 트레이스·불완전 챔버 처리와 연결).
