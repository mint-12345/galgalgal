## 1. #2 전체 데이터 f와 단순 기준선의 상관

### 1.1 결과 (전체 웨이퍼, 라벨 없음)

f_full = (log P1_on − auc_RETAINER_s1) · log(auc_SLURRY_C_s1 · (auc_PCHAMBER_s1 + 0.090) · auc_MAIN_OUTER_s1), 전체 데이터 재적합 상수다.

| 기준선 | A Pearson / Spearman | B Pearson / Spearman | B (극단 웨이퍼 제외) Pearson |
|---|---|---|---|
| B1 에어백 압력 적분 | −0.910 / −0.910 | −0.941 / −0.972 | −0.972 |
| B2 log 에어백 압력 적분 | −0.906 / −0.910 | −0.917 / −0.972 | −0.970 |
| **B3 세 적분의 합** | **−0.978 / −0.995** | **−0.959 / −0.994** | −0.988 |
| B4 세 적분 곱의 log | −0.975 / −0.995 | −0.938 / −0.994 | −0.986 |
| B5 연마 시간 | −0.630 / −0.833 | −0.596 / −0.865 | −0.610 |
| B6 log 연마 시간 | −0.673 / −0.833 | −0.653 / −0.865 | −0.693 |
| G1 f_full 첫 인수 (리테이너 항) | 0.831 / 0.817 | 0.734 / 0.797 | 0.741 |
| G2 f_full 둘째 인수 (log 적분 곱) | −0.975 / −0.995 | −0.939 / −0.994 | −0.986 |

- 점검: 같은 코드로 계산한 fold f와 f_full의 상관이 2026-11-05 `_structure.csv` 값과 1e-9 이내로 일치했다.
- **계획 2절 규칙**: 단일 기준선(B1·B2·B5·B6) 중 두 테이블 모두에서 \|r\| ≥ 0.95인 것은 **없다**. 규칙에 해당하지 않는다.
  - A의 B1은 0.91이다.
  - B의 B1은 0.94이고, 극단 웨이퍼를 빼면 0.97이다.

### 1.2 해석 (비판적으로)

1. **f_full의 변동은 대부분 "세 적분의 크기"다.**
   - 둘째 인수 G2(log 적분 곱)만으로 f_full과 Spearman 0.995다.
   - 세 적분을 그냥 더한 B3도 같은 수준이다.
   - 리테이너 항 G1은 0.73~0.83으로 f의 일부 변동만 설명한다.
   - 즉 f_full은 "세 적분의 합에 가까운 양을 리테이너 항으로 조금 조정한 것"이다.
2. **fold f들과 f_full의 상관 0.95~0.99(2026-11-05)는 특별한 일치가 아니다.** 세 적분의 단순 합도 f_full과 0.96~0.98로 같은 수준이다.
   - 단일 변수 규칙에는 걸리지 않았지만, 단순 조합이 같은 상관을 낸다.
   - 따라서 "구조는 달라도 같은 함수"를 공동 SR의 성과로 내세우지 않는다. 같은 적분 묶음을 쓰면 어떤 조합이든 비슷해진다고 보는 것이 맞다.
3. **적분은 연마 시간을 일부 담고 있다.**
   - 연마 시간과 f_full의 Spearman은 0.83~0.87이고, Pearson은 0.60~0.67로 낮다.
   - 순위 상관이 높은데 선형 상관이 낮은 것은 연마 시간이 특이한 웨이퍼 몇 장의 영향이다.
   - 적분 = (압력·유량 수준) × (시간)이므로, f에는 "얼마나 오래 연마했는가"가 크게 들어 있다.
4. **참고, 표본 내 MRR 상관 (낙관적, 판정에 쓰지 않음)**: f_full 0.703(A)·0.879(B), 세 적분 합 0.686·0.836, 에어백 적분 하나 0.652·0.827.
   - f_full이 단순 합보다 조금 높지만, f_full은 이 라벨로 찾은 식이라 낙관적이다.
   - 실제 추가 예측력은 바깥 fold로 본 #5로 판단한다.

## 2. #5 공유 선형 함수 모형

### 2.1 정의 (계획 3절, 재현 정보는 결과 `.yaml`에 있음)

- **모형**: MRR_i = a_g · (wᵀz_i) + b_g. 이것은 테이블별 LR 계수에 β_A = a_A·w, β_B = a_B·w라는 rank-1 제약을 건 것과 같다.
- **입력**: 각 fold 공동 SR f의 변수(같은 변수 LR과 같음). 공동 SR과 같은 \|중앙값\| 척도에, 그 fold 학습 쪽 평균·SD로 표준화했다. 예측은 표준화와 무관하다(테스트로 확인).
- **식별성**: ‖w‖₂ = 1, a_A > 0, w에 상수항 없음. 자유 모수 p + 3개 (7~8개). 테이블별 LR은 10~12개, 공동 SR은 a·b 4개.
- **추정**:
  - 교대 최소제곱(ALS), 학습 쪽 두 테이블 SSE.
  - 종료: 상대 감소 < 1e-12 또는 5,000회.
  - 초기값: 테이블별 OLS 기울기 행렬의 rank-1 SVD.
- **정규화(penalty)**: 없음. 공동 SR 재적합과 테이블별 LR이 모두 무정규화이기 때문이다.
- **최적화 안정성**:
  - fold마다 무작위 시작 20개 모두 같은 해로 수렴했다. 상대 SSE 차이는 \|1e-13\| 이하, w 각도 차이는 최대 0.0002°다.
  - 반복은 13~20회, 수렴 해의 상대 기울기 노름은 약 2e-7이다.
  - "불안정" 표시는 0/5 fold다.
- **분리**: 평가 쪽 MRR은 채점에만 썼다. 테스트에서 평가 쪽 라벨을 바꿔도 예측이 같았다.
  - 테이블별 LR 예측은 2026-11-05 저장 OOF와 1e-8 이내로 재현됐다.
  - 공동 SR은 저장 OOF를 그대로 썼다.

### 2.4 극단 B 웨이퍼를 채점에서 뺀 사후 민감도

| 대비 | B-456 OOF RMSE 차이 | 구간 | 나은 fold |
|---|---|---|---|
| (i) 공동 SR − 공유 선형 | −0.055 (−1.2%) | [−0.169, +0.042] | 4/5 |
| (ii) 공유 선형 − LR | −0.018 | [−0.104, +0.057] | 4/5 |

- B-456에서 공동 SR이 공유 선형보다 나았던 차이의 약 2/3는 극단 웨이퍼 1장(r = 2)에서 나왔다.
- A-456은 이 웨이퍼와 무관하다.

### 2.5 계수에서 보이는 것

- 공유 선형의 기울기 비 a_A/a_B는 **0.74~0.82**다. 공동 SR의 0.75~0.83과 거의 같다.
  - 즉 "B-456이 같은 지표 변화에 약 1.2~1.35배 크게 반응한다"는 안정성은 **데이터의 성질**이다. 선형 공유에서도 똑같이 나온다.
  - 2026-11-06 사후 해석 2절에서 이를 공동 SR의 성과로 읽은 부분은 이 결과로 약해진다. 공동 SR 고유의 성과로 내세우지 않는다.
- 공유 선형의 원척도 가중치(A 기준)는 챔버 압력 −20~−22, 에어백 −45~−56, 슬러리 −43~−56이다.
  - 테이블별 LR의 가중치는 A가 챔버 압력 약 −50·슬러리 약 0, B가 챔버 압력 약 0·슬러리 약 −75였다.
  - 공유 선형은 그 사이의 타협이다. 이 타협이 A에서 정확도를 잃게 한다 (대비 ii).
- 공동 SR의 비선형 f(예: log(세 적분의 곱), 곱·나눗셈 항)는 이 손실을 없앴다. **왜 그런지는 이번 분석으로 가릴 수 없다.** 가능한 설명은 둘이다.
  - (가) 비선형 조합이 테이블별로 다른 적분 가중치를 흉내 낸다.
  - (나) A-456에 곡률(비선형성)이 있어 그 이득이 공유 비용을 우연히 상쇄했다.
  - 둘을 가르려면 테이블별 비선형 모형 같은 다른 비교가 필요하다.

## 3. 결론: 공동 SR은 공유 선형 함수보다 실질적 이점이 있는가

- **A-456: 있다. 다만 작다.**
  - 미리 정한 기준(OOF RMSE 낮음, 4/5 fold 이상, 구간 0 미포함)을 모두 충족했다.
  - 크기는 RMSE 0.12(2.6%)다. 이 이득은 "선형 공유의 비용(+0.14)을 되찾은 것"이다. 결과적으로 테이블별 LR과 같은 수준이고(차이 +0.02), LR보다 나은 것은 아니다.
- **B-456: 불확실하다.** 방향은 공동 SR 쪽이지만 구간이 0을 포함하고, 차이 대부분이 극단 웨이퍼 1장에서 나왔다.
- **불리한 결과도 그대로 적는다.**
  - (1) f_full과 fold f들의 높은 상관은 세 적분의 단순 합으로도 나온다.
  - (2) 기울기 비의 안정성은 공유 선형에서도 똑같이 나온다.
  - (3) 공동 SR은 여전히 테이블별 LR보다 낫지 않다.
  - (4) 개별 SR보다는 나빴다 (2026-11-04, fold 0).

## 4. 포스터에서 할 수 있는 주장

**할 수 있음 (사후 보조 분석 표시와 함께):**
> In A-456, sharing one *linear* index across the two tables cost accuracy relative to per-table linear regression (out-of-fold RMSE +3.1%, 0/5 folds), whereas the joint SR's shared *nonlinear* function did not (−2.6% vs the shared linear model, better in 5/5 folds, 95% bootstrap CI excludes zero), matching per-table regression. In B-456 the difference was small and uncertain. *(Post-hoc auxiliary analysis; candidate variables pre-selected on all Train+Val data.)*

한국어:
> A-456에서는 두 테이블이 선형 지표 하나를 공유하면 테이블별 선형회귀보다 정확도가 떨어졌지만(OOF RMSE +3.1%), 공동 SR의 비선형 공유 함수는 그 손실 없이 테이블별 선형회귀 수준을 유지했다(공유 선형 대비 −2.6%, 5/5 fold). B-456에서는 차이가 작고 불확실했다.

**할 수 없음:**

| 주장 | 이유 |
|---|---|
| 공동 SR이 선형회귀보다 정확하다 | 테이블별 LR과는 A +0.02, B는 구간 0 포함 (2026-11-05) |
| fold마다 식은 달라도 같은 함수를 찾았다 (특별한 일치) | 세 적분의 단순 합도 f_full과 Spearman 0.995 |
| 기울기 비의 안정성은 공동 SR의 성과다 | 공유 선형도 0.74~0.82로 같음 |
| B-456에서도 비선형 공유가 낫다 | 구간 0 포함, 극단 웨이퍼 영향 |
| 특정 수식(전체 데이터 f)이 검증됐다 | 구조 재현 1/5, 2026-11-05 결론 그대로 |
| 비선형 공유가 테이블 차이를 설명한다 (메커니즘) | 2.5절 (가)·(나)를 가르지 못함 |

2026-11-05 결론 문구("수식 구조의 재현성이 낮음")와 그림은 그대로다. 위 문장은 그 옆에 덧붙이는 보조 주장이다.
