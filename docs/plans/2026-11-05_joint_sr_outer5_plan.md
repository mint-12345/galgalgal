# 공동 SR 바깥 5-fold 추가 검증 계획 (사후 추가 검증)

- 작성: 전준혁, 2026-11-05. 브랜치 `sr/joint` (로컬 전용).
- **성격: 사후 추가 검증.** 2026-11-04 공동 SR 결과(판정 "공통 형태 없음")와 바깥 fold 0 결과를 본 뒤 정했다.
  사전등록이 아니고 독립 test 평가도 아니다. 기존 계획(`2026-11-04_joint_sr_plan.md`, 커밋 3949cb4)의 판정 규칙과 결과는 바꾸지 않는다.
- 이 문서는 fold 1~4 탐색을 시작하기 전에 커밋한다. 이후 바꾸는 내용은 맨 아래 변경 기록에 남긴다.

## 1. 목적

1. 바깥 fold 0 하나로 끝난 "탐색과 평가를 분리한 검증"을 반복 0의 5개 fold 전체로 넓힌다.
2. 각 fold에서 새로 찾은 공동 SR과 **같은 변수의 테이블별 선형회귀**를 같은 평가 웨이퍼에서 비교한다.
3. 5번의 독립 재탐색에서 f의 변수·구조가 반복되는지 본다.
4. 포스터용 그림을 만든다.

개별 SR은 다시 탐색하지 않는다.

## 2. 설계

| 항목 | 내용 |
|---|---|
| 바깥 fold | `folds_v1` 반복 0의 fold 0~4 (r = 0~4). 웨이퍼마다 정확히 한 번 평가 쪽 |
| fold 0 | 기존 탐색 캐시(`holdout_joint_p0~p4.jsonl`, 커밋 c3542df 결과)를 재사용. 새로 탐색하지 않음. 같은 코드로 다시 평가해 기존 RMSE(공동 5.069 / 4.412, LR 5.009 / 4.428)와 일치하는지 확인 |
| fold 1~4 | 새로 탐색 |
| 웨이퍼 | A-456 940장, B-456 951장 (2026-11-04와 같음) |
| 후보 변수 | 기존 14개 (정식 SR 후보 합집합) |
| 척도 | 두 테이블 합산 \|중앙값\| (train+val 전체, 라벨 미사용). 기존과 같음 |
| 탐색 | `sr_joint_search.make_model` 그대로: 템플릿 `a[g]·f(14개) + b[g]`, niterations 500, populations 31, population_size 27, deterministic, parallelism serial, 지수 제한 손실, 시드 42~51. **설정 축소 없음** |
| 탐색 데이터 | 바깥 학습 쪽(약 80%)만. 바깥 평가 쪽 웨이퍼는 X·y 모두 탐색에 넣지 않음 |
| 후보 정리 | 10개 시드의 파레토 식을 모아 지수 범위(±3) 밖 식 제외, 같은 식 하나로 (기존 규칙) |
| 식 선택 | 바깥 학습 쪽 안의 반복 0 나머지 4 fold에서 각 후보를 공동 재적합·채점. 점수 = (A RMSE + B RMSE)/2의 4 fold 평균, SE = sd/√4. 복잡도별 최저 점수 곡선에서 1-표준오차 규칙 (기존과 같음) |
| 최종 적합 | 선택 f의 공통 내부 상수 + a_A·b_A·a_B·b_B를 바깥 학습 쪽 전체에서 비선형 최소제곱 (기존 `joint_refit`) |
| 비교 모형 | 그 fold의 f가 쓴 **같은 변수**로 A·B 각각 선형회귀(절편 포함), 바깥 학습 쪽에서 적합 |
| 참고 행 | 학습 쪽 테이블 평균, 후보 14개 테이블별 선형회귀. 결론에 쓰지 않음 |

**바깥 평가 쪽 MRR은 탐색·선택·계수 추정에 쓰지 않고 채점에만 쓴다.**
테스트에서는 평가 쪽 라벨만 바꿔도 선택 식·계수·예측이 그대로인지 확인한다.

### 평가 데이터가 영향을 줄 수 있는 부분 (완전한 외부 검증이 아닌 이유)

- **후보 14개**: 정식 SR(2026-11-01)이 전체 train+val 라벨로 고른 후보의 합집합이다. 각 fold의 평가 웨이퍼 라벨이 후보 선정에 들어갔다.
- **척도**: 평가 웨이퍼의 변수 값이 \|중앙값\| 계산에 들어간다. 라벨은 쓰지 않는다.
- **fold 배정과 교체 구간**: 라벨 없이 정해졌다.
- **결정 시점**: 이번 추가 검증을 할지, 무엇과 비교할지는 전체 데이터 결과와 fold 0 결과를 본 뒤 정했다.

## 3. 지표와 집계

- **fold별**: A·B 각각 공동 SR과 LR의 RMSE·MAE·MSE, n_eval, n_train. 차이 = 공동 SR − LR (음수면 공동 SR이 나음).
- **5-fold**: fold별 RMSE·MAE의 평균과 표준편차(ddof 1), 차이의 평균·표준편차, 공동 SR이 나았던 fold 수.
- **OOF**: 5개 평가 fold 예측을 합쳐(웨이퍼마다 한 번) 계산한 RMSE·MAE. fold 평균 RMSE와 다를 수 있으므로 구분해서 보고한다.
- **통계 검정**: fold가 5개뿐이라 판정에 쓰지 않는다. Nadeau–Bengio 보정 t(비율 ≈ 0.25, 자유도 4)는 참고로만 적는다.
- **성능 분류** (결과 전 정의, 각 테이블):

| 분류 | 조건 |
|---|---|
| 공동 SR 우세 | OOF RMSE가 LR보다 낮고, 5개 fold 중 4개 이상에서 공동 SR이 나음 |
| LR 우세 | OOF RMSE가 LR보다 높고, 5개 fold 중 4개 이상에서 LR이 나음 |
| 차이 불확실 | 그 밖 |

## 4. 수식 구조의 재현성 (결과 전 정의)

각 fold의 선택 f를 2026-11-04 전체 데이터 최종 f와 비교한다.
전체 데이터 최종 f는 `(log(P1_on) − auc_RETAINER_s1)·log(auc_SLURRY_C_s1·(auc_PCHAMBER_s1+0.090)·auc_MAIN_OUTER_s1)`이다.

1. **문자열 일치**: 탐색 식 문자열이 같은가. 상수를 c로 바꾼 골격(`sr_select.skeleton`)이 같은가.
2. **변수**: fold별 사용 변수, 변수별 등장 fold 수(5회 중), 전체 데이터 최종 f 변수 집합과의 Jaccard 계수.
3. **사전 정의 구조 S\***: "리테이너 압력 항 × log(압력·슬러리 적분 곱)". 판정 방법:
   - 맨 바깥의 상수 덧셈·상수 곱·부호를 벗긴다. 이 부분은 a_g·b_g가 흡수한다.
   - 남은 식이 두 인수의 곱이어야 한다.
   - 한 인수가 log(·)이고, 그 인자에 {auc_SLURRY_C_s1, auc_PCHAMBER_s1, auc_MAIN_OUTER_s1} 중 2개 이상이 들어 있어야 한다.
   - 다른 인수에 auc_RETAINER_s1이 들어 있어야 한다.
   - 전체 데이터 최종 f와 fold 0 f는 이미 S\*에 해당한다. 이 정의는 2026-11-04 보고서에 관찰로 적은 골격을 그대로 옮긴 것이다.
4. **기능 유사성**: 각 fold f(바깥 학습 쪽 재적합 상수)와 전체 데이터 최종 f(전체 재적합 상수)의 값을 A·B 웨이퍼 전체에서 계산한다. 테이블별로 Pearson 상관을 구한다. 관계를 비교할 뿐 같은 식이라는 근거로 쓰지 않는다.
5. **그룹별 계수**: fold별 a_A, b_A, a_B, b_B. 서로 다른 f끼리는 a 크기를 비교하지 않고 부호와 a_A/a_B 비만 본다.

**구조 반복 분류** (결과 전 정의):

| 분류 | S\* 해당 fold 수 |
|---|---|
| 구조 반복 | 4개 이상 / 5 |
| 부분 반복 | 2~3개 |
| 반복 낮음 | 1개 이하 |

구조가 다르면 같은 관계라고 해석하지 않는다.

## 5. 결론 문구 선택 (포스터, 결과 전 정의)

| 구조 분류 | 성능 분류 (A·B) | 결론 방향 |
|---|---|---|
| 구조 반복 | 두 테이블 모두 공동 SR 우세 | "공통 수식이 반복적으로 발견되고 예측 성능도 유지됨" |
| 구조 반복 또는 부분 반복 | 그 밖 | "수식 구조는 유사하지만 선형회귀 대비 개선은 불확실" (LR 우세면 그대로 적음) |
| 반복 낮음 | 무관 | "수식 구조의 재현성이 낮음" |

전체 데이터로 찾은 최종 f는 이번 5-fold 검증의 대상이 아니다. 5-fold 성능은 "fold마다 새로 찾은 f들"의 성능이다.

## 6. 극단 웨이퍼 사후 민감도

- 대상: B-456 웨이퍼 1장(WAFER_ID −4230160594, 연마 시간 98초). 2026-11-04 결과를 본 뒤 주목했다. 반복 0의 fold 2에 있다.
- **주 결과는 전체 웨이퍼 기준이다.** 아래는 사후 민감도로만 제시하고, 주 결론을 바꾸지 않는다.
  - (i) **score_only**: 기존 예측에서 그 웨이퍼만 채점에서 뺀다.
  - (ii) **refit_without**: 각 fold의 선택 f는 그대로 두고, 두 모형 계수를 그 웨이퍼 없이 다시 적합한 뒤 채점에서도 뺀다.
- 탐색은 다시 하지 않는다. 그래서 fold 1·3·4의 탐색 학습 쪽에는 이 웨이퍼가 남아 있다.

## 11. 해석으로 정한 것

- "같은 변수의 선형회귀"는 각 fold의 선택 f에 들어간 변수만 쓴다. 그래서 fold마다 변수가 다를 수 있다.
- 안쪽 4 fold는 반복 0의 다른 fold를 그대로 쓴다(fold 0과 같은 방식). 바깥 학습 쪽 웨이퍼만 들어간다.
- fold 0의 1-표준오차 규칙은 기존 코드(SE = sd/2)와 같다.
