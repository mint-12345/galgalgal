## 1. 질문과 모형

질문: 두 테이블에서 찾은 식이 달라도, 공통 함수 f에 테이블별 크기·수준만 달리 주면 두 테이블의 MRR을 함께 설명할 수 있는가.

```
MRR_g = a_g · f(x) + b_g        g ∈ {A-456, B-456}
f의 형태·변수·내부 상수: 두 테이블 공통
a_g, b_g: 테이블별 (테이블 구분값은 f 안에 들어가지 않는다)
```

- x는 실제 변수 이름으로 적는다. 압력(P)·상대속도(V) 기호는 쓰지 않는다.
- "그룹 변수를 하나 더 넣은 SR"은 이 가설의 검증으로 보지 않는다(구분값이 f 안에 들어갈 수 있기 때문).

## 4. 척도

- 변수 ÷ \|중앙값\|, 부호 유지. MRR은 원척도.
- **주 처리: 두 테이블을 합친 train+val 전체의 \|중앙값\|** (위 표 "합산"). f를 공유하려면 두 테이블에서 x의 의미가 같아야 하기 때문.
- 민감도: 테이블별 \|중앙값\| (A는 A 값, B는 B 값으로 나눔).
- 척도는 라벨을 쓰지 않지만 평가 fold 웨이퍼의 피처 값도 쓴다(정식 SR 4.8 1번과 같은 예외). 최종 f에 한해 fold 학습 쪽만으로 계산한 척도 민감도를 추가로 본다.

## 5. fold와 누수 점검

- `folds_v1.csv` 25개(r = repeat × 5 + fold). 각 fold의 학습 쪽 = 두 테이블의 학습 조각 합집합, 평가는 테이블별로 따로.
- A·B 공유 WAFER_ID 405개(공동 웨이퍼 안 368개)는 **반복 5회 모두 같은 조각에 있다**(어긋남 0, 라벨 미사용 확인). 매뉴얼 조건 충족.
- fold 크기: 테이블별 평가 183~194장.
- 코드에서 매 fold마다 (1) 학습·평가 쪽 키·WAFER_ID 겹침 0, (2) 계수 추정 함수가 평가 쪽 MRR을 받지 않음을 확인한다.

## 6. 1단계: 정식 파레토 식 걸러 보기 (새 SR 없음)

- 후보: `results/2026-11-01_박종화_FV1_sr_pareto.csv` 281행 → 같은 식 문자열을 하나로(246개). 변수가 없는 식(상수만)은 f가 아니므로 순위에서 뺀다(개수 보고).
- 각 식을 f로 두고 fold마다 학습 쪽에서 f 내부 상수(공통) + a_A, b_A, a_B, b_B를 **한 번에** 비선형 최소제곱으로 맞춘다.
  - `sr_select`의 파싱·예측·지수 범위(−3~3)·반복 상한(`max_nfev = 200`)을 그대로 쓴다. 초기값: f 상수 = 원래 식 상수, a_g·b_g = 그 f로 테이블별 단순회귀.
  - 학습 쪽 예측이 계산되지 않는 웨이퍼는 잔차 1e6(정식 `refit`과 같은 처리).
- 지표: 테이블별 평가 RMSE의 25 fold 평균. 순위 = 두 테이블 값의 평균. 평가 쪽 예측이 하나라도 계산되지 않는 식은 뺀다(개수 보고).
- 상위 5개의 식·복잡도·테이블별 RMSE/MAE/MSE와 7절 기준선을 같은 웨이퍼·fold로 보고. 상위 1개 대 (가)의 보정 t-검정은 참고.
- **선택 낙관성 있음, 판정에 쓰지 않음.**
- 민감도: 테이블별 척도. 상위 5개는 `max_nfev = 2000`으로도 계산해 수렴을 확인.

## 7. 2단계: 공동 SR 새 탐색

- **방식 A (우선): PySR 2.7.2 `TemplateExpressionSpec`**
  `combine = "a[g] * f(x1, …, x14) + b[g]"`, `expressions = ["f"]`, `parameters = {a: 2, b: 2}`, g = 1(A-456)·2(B-456).
  f는 14개 변수만 받고 g는 받지 않는다. f 내부 상수는 하나라 두 테이블이 공유한다.
- **실행 전 인공 데이터 검증(라벨 없음):** 알려진 f와 a_g·b_g로 만든 두 그룹 데이터에서 (1) 템플릿이 돌아가는지, (2) f가 g를 받지 않는지,
  (3) a·b가 그룹별로 추정되는지, (4) 지수 차단 loss가 템플릿에서 작동하는지 확인한다.
  **하나라도 실패하면 방식 B**로 간다(결과를 보기 전에 정하는 규칙).
- 방식 B (대안): MRR을 테이블별로 표준화해 합친 뒤 일반 PySR로 f를 찾고, 찾은 f에 a_g·b_g를 fold별로 다시 맞춘다.
  탐색 중 a_A/a_B 비율이 두 테이블 MRR 표준편차 비로 고정되는 **근사**이며 방식 A와 같지 않다. 결과에 명시한다.
- 설정은 정식 SR(`src/sr_run.py`)과 같게: 시드 42~51, `niterations = 500`, `populations = 31`, `population_size = 27`,
  `maxsize = 20`(f의 복잡도), 연산자 `+ − × ÷ ^ exp log sqrt`, `constraints = {"^": (-1, 1)}`, 중첩 금지, 연산자 가중치(exp·log 3, sqrt·^ 2),
  `deterministic = True`, `parallelism = "serial"`, 지수 차단 loss(템플릿용으로 f 트리를 검사하게만 바꿈).
  입력은 4절 합산 척도의 14개 변수, 출력은 원척도 MRR.
- 후보: 10개 시드 파레토의 f를 모두 모아 같은 식은 하나로. 사후 지수 점검(정식 4.8 5번)으로 뺀 수를 보고.
- 선택: 각 f를 6절과 같은 방법(f 상수 공통 + a_g·b_g, fold마다 재적합)으로 평가.
  fold 지표 = 그 fold에서 두 테이블 평가 RMSE의 평균. 복잡도마다 25 fold 평균이 가장 낮은 식을 남기고,
  **1-표준오차 규칙**(최솟값 + 표준오차 1개 안에서 복잡도 최소, 표준오차 = fold 지표 sd(ddof=1)/√25)으로 최종 f.
  민감도: 배율 1.00/1.02/1.05/1.10.
- 시간: 정식 SR이 시드당 약 3~4분(950장)이었으니 1,891장이면 시드당 약 6~10분, 10개 시드에 1~2시간으로 예상한다.
  짧은 시험(시드 42, 적은 반복)으로 실제 속도를 먼저 재고, 시드마다 결과를 파일에 덧붙여 중단 후 이어 돌릴 수 있게 한다.
  정식 설정을 줄여서 돌리면 "줄인 설정"이라고 결과에 적는다.

## 9. 판정 (2단계 최종 f 기준, 매뉴얼 8절)

테이블 g마다 fold별 평가 MSE 차이 d = 공동 모형 − (가)로 보정 t-검정(Nadeau & Bengio, J = 25, df = 24, 양측,
비율 = 그 테이블의 평가 / 학습 장수, `cv_common.corrected_ttest`). "(가)보다 낮음" = 평균 차이 < 0 이고 p < 0.05.

| 판정 | 조건 |
|---|---|
| 공통 형태 있음 | 두 테이블 모두 (가)보다 낮음, **그리고** 각 테이블에서 RMSE(공동) − RMSE(다) ≤ SE(다) |
| 부분적 | 한 테이블에서만 (가)보다 낮음, 또는 두 테이블 모두 (가)보다 낮지만 어느 한 테이블에서 RMSE(공동) − RMSE(다) > SE(다) |
| 공통 형태 없음 | 어느 테이블에서도 (가)보다 낮지 않음 |

- SE(다) = (다)의 그 테이블 fold RMSE 표준편차(ddof=1)/√25. 정식 SR 1-표준오차 규칙과 같은 정의.
- 경계: p가 0.04~0.06이거나 RMSE 차이가 SE(다)의 ±10% 안이면 판정 옆에 "경계"를 붙인다. 규칙은 바꾸지 않는다.
- 판정은 **예측 구조에 대한 것**이고 물리적 인과를 입증하지 않는다. "공통 형태 없음"이 나와도 공통 관계가 없다고 단정하지 않는다
  (유의하지 않음 ≠ 없음).
- 1단계와 2단계의 수치는 모두 식 선택에 쓴 교차검증 위에서 나온 것이라 낙관적이다. 독립 검증이라고 쓰지 않는다.

## 10. 판정에 쓰지 않는 추가 보고

1. 최종 f와 a_g·b_g: f를 두 테이블 합친 학습 데이터 기준 평균 0·표준편차 1로 바꿔 a_g(MRR / f 1 표준편차), b_g를 보고.
   a_A/a_B 비와 부호 일치 여부도 적는다(f의 바깥 상수는 a_g·b_g와 겹쳐 따로 정해지지 않기 때문).
2. 교체 주기별 안정성: 헤드 부품 리셋 구간(`sr_select.head_reset_intervals`)마다 f를 고정하고 a_g·b_g만 다시 맞춰 변동계수와 부호.
   구간 최소 웨이퍼 max(10, 2 × (상수 수 + 1)), 빠진 구간 수 보고.
3. 공유 WAFER_ID 제외 민감도: 공동 웨이퍼에서 공유 ID(368개) 웨이퍼를 두 테이블 모두에서 빼고 같은 평가.
4. 테이블별 척도 민감도, fold 학습 쪽 척도 민감도(최종 f만).
5. 정의역 오류(sqrt 음수, log 0 이하, 0으로 나눔, 음수 밑 비정수 지수)와 수렴 실패·계산 불가 식 수.
6. 시간이 허락하면: 선택 편향을 줄인 **부분 중첩 검증** — 반복 0의 5개 바깥 fold마다 바깥 학습 쪽 안의 4-fold로
   후보 f를 고르고 바깥 평가 쪽에서 채점(1단계 후보, 2단계 후보 각각). 파레토 탐색 자체는 전체 데이터를 썼으므로 이것도 완전한 독립 검증은 아니다.
