# 공동 SR 후속 실험 계획 (사전 고정)

> 상태: **실행 전 고정 문서.** 이 파일을 커밋한 뒤에 결과를 만든다. 커밋 시각이 사전 고정의 근거다.
> 성격: 정식 SR(PR #27) 판정 이후의 **사후 후속 실험**이다. 정식 SR 판정은 바꾸지 않는다.
> 작성: 김혜연 · 계획 고정일: 2026-11-06 · 관련: PR #27(sr/results), main 61d7178(전준혁 교차 적용)

## 1. 질문
A-456과 B-456에 **공통 형태 f(x)** 가 있고, 차이는 테이블별 크기·수준(a_g, b_g)뿐인가?

```
MRR_g = a_g · f(x) + b_g     (g = A-456, B-456)
f와 f 안의 상수는 두 테이블 공통, a_g·b_g만 테이블별
```

- 배경: 정식 SR은 두 그룹에서 다른 식을 찾았다. 교차 적용에서는 상대 식의 상수만 다시 맞추면 RMSE A 4.722, B 5.101로, 자기 식(4.240, 4.177)보다 유의하게 나쁘고 그 변수 선형회귀(4.710, 4.998)와 비슷했다. 오차의 큰 부분은 두 그룹의 MRR 수준 차이(평균 73.5 대 80.3)였다.
- 표기: P(압력), V(상대속도)는 쓰지 않는다. V는 데이터에 없고 P는 설정값이 고정이다. 변수는 실제 이름(압력 적분, 연마 시간, 소모품 사용량 등)으로 적는다.

## 2. 데이터
| 항목 | 결정 |
|---|---|
| 웨이퍼 | 정식 SR과 같은 집합. A-456 940장, B-456 951장, train+val만 |
| 라벨 | `load_labels()`로 읽음. test MRR, `data/locked/` 사용 안 함 |

| 척도 (주) | 두 그룹을 합친 train+val의 \|중앙값\|으로 나눔. f를 공유하려면 두 테이블에서 x의 의미가 같아야 하기 때문 |
| 척도 (민감도) | 그룹별 \|중앙값\| (정식 SR 방식) |

## 3. fold
- `folds_v1.csv` 25 fold를 쓴다.
- 실행 전 확인: 두 그룹에 모두 있는 WAFER_ID 405개가 모든 fold에서 같은 쪽(학습 또는 평가)에 있어야 한다. 어긋나면 실행하지 않고 팀에 보고한다.
- a_g, b_g, f 안의 상수는 모두 각 fold의 학습 쪽에서만 맞춘다.

## 4. 단계
**1단계: 기존 파레토 식 걸러 보기 (새 SR 없음)**
- 정식 SR 파레토 식 281개 각각을 f 후보로 둔다. f 안의 상수는 두 그룹 공통, a_g·b_g는 테이블별로 fold 학습 쪽에서 다시 맞춘다.
- 두 그룹 평가 RMSE의 평균으로 순위를 매기고 상위 5개를 보고한다. 여러 식을 골라 본 것이므로 "선택 낙관성 있음"으로 표시한다.
- 1단계는 판정에 쓰지 않는다. 판정은 2단계로 한다.

**2단계: 공동 SR (새 탐색)**
- PySR의 범주별 매개변수 기능(ParametricExpressionSpec, TemplateExpressionSpec 등)을 쓸 수 있으면 그것으로 한다.
- 프로젝트 `.venv`의 PySR은 업그레이드하지 않는다. 필요하면 별도 환경을 만들고 버전을 기록한다.
- 기능이 없으면 대안: 목표값을 그룹별로 표준화한 뒤 합쳐 PySR로 f를 찾고, 찾은 f에 a_g·b_g를 fold별로 다시 맞춘다. a_g의 비율이 고정되는 근사라는 점을 기록한다.
- 설정은 정식 SR과 같다: 시드 42~51, 500 iter, f의 복잡도 ≤ 20, 같은 연산자·지수 규칙, 1-표준오차 규칙으로 최종 f 선택.

## 5. 기준선 (같은 웨이퍼·같은 fold)
| 기호 | 기준선 | 용도 |
|---|---|---|
| (가) | 그룹별 선형회귀: 같은 변수, 절편·기울기 모두 그룹별 | **핵심 비교 대상** |
| (나) | 공통 기울기 + 그룹별 절편 선형회귀 | 참고 |
| (다) | 정식 SR 그룹별 최종 식 (A 4.240, B 4.177) | 상한 참고. 같은 fold로 골라 낙관적 |
| (라) | RF, 학습 쪽 평균 | 참고 |

## 6. 판정 (2단계 최종 f 기준)
검정: MSE의 fold별 쌍 차이로 Nadeau–Bengio 보정 t-검정.

| 판정 | 조건 |
|---|---|
| 공통 형태 있음 | 두 그룹 **모두**에서 공동 모형이 (가)보다 낮고 p < 0.05, **그리고** 각 그룹에서 (다)와의 RMSE 차이가 fold 표준오차 1개 이내 |
| 부분적 | 한 그룹에서만 (가)보다 유의하게 낮음, 또는 두 그룹 모두 (가)보다 낮지만 (다)보다 1 표준오차 넘게 나쁨 |
| 공통 형태 없음 | 어느 그룹에서도 (가)보다 유의하게 낮지 않음 |

추가 보고 (판정에 쓰지 않음):
- 교체 주기별로 a_g·b_g를 다시 맞춘 변동계수 (그룹 안에서도 계수가 흔들리는지)
- 공유 WAFER_ID를 뺀 웨이퍼에서의 민감도
- 그룹별 척도 민감도
