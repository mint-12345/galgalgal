## 1. 목적

공동 SR이 잡은 예측 관계가 다음 둘 중 무엇에서 오는지 구분한다.
- (가) 적분 변수들의 단순한 상관
- (나) 공유 **비선형** 함수가 주는 추가 예측력

## 2. #2 전체 데이터 f와 단순 기준선의 상관 (라벨 없음)

- **f_full**: 2026-11-04 전체 데이터 최종 f. 상수는 전체 데이터 재적합값이다 (`sr_joint_outer5.structure_table`과 같은 계산).
  - 점검: 같은 코드로 계산한 fold f와 f_full의 상관이 저장된 `_structure.csv` 값과 1e-9 이내로 같아야 한다.
- **입력**: 공동 SR과 같은 척도(합산 \|중앙값\|)를 쓴다. A-456 940장, B-456 951장.
- **기준선**:

| 코드 | 정의 |
|---|---|
| B1 | 에어백 압력 적분 `auc_MAIN_OUTER_s1` |
| B2 | log(B1) |
| B3 | 세 적분의 합: MAIN_OUTER + SLURRY_C + PCHAMBER |
| B4 | 세 적분 곱의 log: log MAIN_OUTER + log SLURRY_C + log PCHAMBER |
| B5 | 연마 시간 `dur_POLISH_s1` |
| B6 | log(B5) |
| G1 | f_full의 첫 인수 (log P1_on − auc_RETAINER_s1). 분해용 |
| G2 | f_full의 둘째 인수 log(∫Q_C·(∫P_ch + c)·∫P_bag). 분해용 |

- **지표**: 테이블별 Pearson·Spearman 상관 (f_full과의 상관).
  - 사후 민감도: 극단 B 웨이퍼를 뺀 값.
- **참고**: f_full과 각 기준선의 MRR 상관 (train+val, 표본 내).
  - f_full은 이 라벨로 찾았으므로 낙관적이다. 성능 비교는 #5의 바깥 fold로만 한다.
- **해석 규칙 (계산 전 고정)**: 단일 기준선(B1·B2·B5·B6) 중 하나라도 두 테이블 모두에서 f_full과 \|r\| ≥ 0.95이면, fold f들과 f_full의 높은 상관(0.95~0.99)을 "특별한 함수적 일치"의 근거로 쓰지 않는다.

## 3. #5 공유 선형 함수 모형

### 3.1 모형

MRR_i = a_g(i) · (wᵀ z_i) + b_g(i), g ∈ {A-456, B-456}

- **x**: 각 fold에서 공동 SR이 고른 f의 변수 (같은 변수 LR과 같음). 공동 SR과 같은 척도로 나눈 값이다.
- **z**: x를 그 fold **학습 쪽**의 평균·표준편차(두 테이블 합산)로 표준화한 값.
  - 표준화는 계산 안정성과 정규화 규약 때문이다.
  - 예측값은 x의 아핀 변환에 대해 변하지 않는다 (상수항은 b_g가 흡수).
- 이 모형은 테이블별 LR 계수 벡터를 β_g = a_g·w로 묶는 **계수 행렬 rank-1 제약**과 같다.
  - 자유 모수는 p + 3개다 (p = 변수 수). 테이블별 LR은 2(p + 1)개, 공동 SR은 a·b 4개 + f 내부 상수(이번 5개 fold는 0개)다.

### 3.2 식별성

- (a_g, w) → (c·a_g, w/c)로 바꿔도 같은 모형이다. 그래서 **‖w‖₂ = 1, a_A > 0**으로 고정한다. 수렴 뒤 다시 정규화한다.
- a_A = a_B = 0이면 w가 정해지지 않는다. 그 경우 실패로 기록한다.
- w에는 상수항을 두지 않는다 (b_g가 흡수).

### 3.3 추정과 최적화 안정성

- **목적함수**: 학습 쪽 두 테이블 잔차 제곱합 (웨이퍼마다 같은 가중치). 공동 SR 재적합(`joint_refit`)과 같은 최소제곱이다.
- **정규화(penalty): 없음.**
  - 공동 SR 재적합과 테이블별 LR이 모두 무정규화라서, 정규화를 넣으면 비교가 섞인다.
  - p ≤ 5, 학습 웨이퍼 약 1,510장이다.
- **교대 최소제곱(ALS)**. 각 단계가 SSE를 줄이므로 단조 수렴한다.
  1. w가 주어지면 테이블별로 y를 s = Zw에 OLS 회귀해 a_g, b_g를 구한다.
  2. a, b가 주어지면 (y_i − b_g)를 a_g·z_i에 상수항 없이 OLS 회귀해 w를 구한다.
  3. 정규화하고 반복한다. 종료 조건은 SSE 상대 감소 < 1e-12 또는 5,000회다.
- **초기값 (결정적)**: 학습 쪽 테이블별 OLS 기울기 행렬 [β_A, β_B]의 rank-1 SVD 첫 왼쪽 특이벡터.
- **안정성 점검**: fold마다 무작위 시작 20개 (w ~ N(0, I) 정규화, SEED 42).
  - 주 결과는 SVD 시작 해다.
  - 보고 항목: 무작위 시작 해들과의 최대 SSE 상대 차이, w 사이 최대 각도, 반복 횟수.
  - SSE 상대 차이가 1e-6을 넘으면 "불안정"으로 표시하고 그대로 보고한다.
- **교차 점검**: 수렴 해에서 목적함수의 기울기 노름이 충분히 작은지 기록한다.

### 3.4 평가

- 분할: `folds_v1` 반복 0의 fold 0~4 (2026-11-05와 같음).
- 학습 쪽만으로 w·a·b를 적합한다. **평가 쪽 MRR은 채점에만 쓴다.** 테스트에서 평가 쪽 라벨을 바꿔도 예측이 같은지 확인한다.
- 비교 모형:
  - 공동 SR: 저장된 OOF 예측 그대로
  - 테이블별 LR(같은 변수): 다시 적합해 저장값과 1e-8 이내로 같은지 확인
  - 공유 선형: 새로 적합
- **두 대비**:
  - (i) 공동 SR − 공유 선형: 공유한 상태에서 비선형 f의 이득
  - (ii) 공유 선형 − 테이블별 LR: 공유(rank-1) 제약의 비용
- 지표:
  - fold별 RMSE·MAE·MSE
  - 5-fold 평균·SD
  - OOF RMSE·MAE
  - 나은 fold 수
  - 웨이퍼 부트스트랩 95% 구간: fold 층화, 2,000회, SEED 42, 적합된 예측 고정
- 극단 B 웨이퍼: 채점에서만 빼는 사후 민감도. 주 결과는 전체 웨이퍼다.

### 3.5 분류 (계산 전 고정, 테이블별)

| 대비 (i) 분류 | 조건 |
|---|---|
| 공동 SR 우세 | 공동 SR의 OOF RMSE가 더 낮고, 5개 fold 중 4개 이상에서 나음 |
| 공유 선형 우세 | 반대 |
| 차이 불확실 | 그 밖 |

- **"실질적 이점"이라고 쓰는 조건**: 공동 SR 우세이면서 부트스트랩 95% 구간 상한 < 0.
  - 우세이지만 구간이 0을 포함하면 "우세하지만 불확실"로 쓴다.
- 대비 (ii)도 같은 규칙으로 분류한다 ("공유 비용 있음 / 없음 / 불확실").
- 이 분류는 사후 보조 분석이다. 2026-11-05 결론 문구를 바꾸지 않는다.
